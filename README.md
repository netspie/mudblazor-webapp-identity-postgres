# Blazor Web App with Identity, PostgreSQL and MudBlazor

This is a template Blazor Web App project you can use to get your identity setup with PostgreSQL, snake-case naming convention and MudBlazor component library installed.

### Tech
Blazor, .NET 9.0.4, EF Core 9, Identity, MudBlazor 8
